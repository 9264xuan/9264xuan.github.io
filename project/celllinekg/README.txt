CellLineKG project page files

1. Upload index.html, style.css, and the assets folder to your GitHub Pages repository.
2. Put manuscript figures into assets with these filenames:
   - fig1.png : overview figure
   - fig2.png : validation figure (optional)
   - fig3.png : multi-condition cell-line selection figure (optional)
   - fig4.png : integrated evidence retrieval figure (optional)
3. If using a personal GitHub Pages repository named 9264xuan.github.io, place these files under:
   project/celllinekg/
4. The resulting URL will be:
   https://9264xuan.github.io/project/celllinekg/
5. After a preprint/paper is public, replace the disabled Paper button and update the Citation section.
